# Danh sách tính năng ứng dụng Sản xuất

Phiên bản app: 2.6.8 (17/08/2026). Cột **Object liên quan** ghi slug chuẩn của Object lưu trữ hoặc cung cấp dữ liệu cho tính năng.

| Nhóm | Tính năng | Mô tả ngắn | Object liên quan |
