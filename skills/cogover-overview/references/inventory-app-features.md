# Inventory App Feature List

Phiên bản app: 1.6.8 (17/08/2026). Cột **Object liên quan** ghi slug chuẩn của Object lưu trữ hoặc cung cấp dữ liệu cho tính năng.

| Cấu hình | Tuyến cung ứng và luồng nhiều bước | Sắp xếp tuyến theo độ ưu tiên và các chặng; chọn vị trí phù hợp theo loại luồng, kho, khách hàng/nhà cung cấp và sản phẩm.
